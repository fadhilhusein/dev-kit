
## UI components
- Build UI sections with the `tailwind-components` skill (dev-kit: `dev-kit:tailwind-components`). It copies only the needed components from the bundled Tailwind v4 library into `src/components/ui/` as TypeScript.
- Requires Tailwind v4 and the deps `@headlessui/react` and `@heroicons/react`.
- Do not hand-write what the library already provides; adapt it. Do not paste library code into public repos or docs.
